# Prijedlog teme

## Naslov

**Informacioni sistem za upravljanje digitalnom kolekcionarskom kartaškom igrom Astral Nexus**

## Kratak opis

Astral Nexus je web informacioni sistem za upravljanje digitalnom kolekcionarskom kartaškom igrom. Sistem omogućava registraciju i autentifikaciju korisnika, upravljanje korisničkim profilom, pregled kolekcije karata, kreiranje i uređivanje špilova prema definisanim pravilima, otvaranje paketa karata, vođenje statistike mečeva i osnovni modul za upravljanje tokom partije. Administratorska upravljačka ploča omogućava CRUD upravljanje kartama i administraciju korisnika.

Sistem je razvijen u .NET Core okruženju koristeći C# i ASP.NET Core, dok se za trajnu pohranu korisnika, karata, kolekcija, špilova, paketa i historije mečeva koristi Microsoft SQL Server uz Entity Framework Core. Sistem dodatno izlaže REST API za pristup glavnim resursima aplikacije.
